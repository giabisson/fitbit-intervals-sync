# Fitbit (Google Health API) to Intervals.icu Sync

Automatically synchronizes daily health metrics, sleep data, and fitness vitals from Google Health API (Fitbit devices) to [Intervals.icu](https://intervals.icu).

---

## 📊 Synced Metrics

| Metric | Google Health API Source | Intervals.icu Field | Unit / Format |
| :--- | :--- | :--- | :--- |
| **Resting Heart Rate** | `daily-resting-heart-rate` | `restingHR` | Beats per minute (bpm) |
| **Heart Rate Variability** | `daily-heart-rate-variability` | `hrv` | rMSSD (ms) |
| **Sleep Duration** | `sleep` | `sleepSecs` | Seconds |
| **Sleep Score / Quality** | `sleep` | `sleepScore` | 0–100 score |
| **Body Weight** | `weight` | `weight` | Kilograms (kg) |
| **Body Fat** | `body-fat` | `bodyFat` | Percentage (%) |
| **Oxygen Saturation** | `daily-oxygen-saturation` | `spO2` | Percentage (%) |
| **Respiratory Rate** | `daily-respiratory-rate` | `respiration` | Breaths per minute |
| **VO2 Max** | `daily-vo2-max` / `vo2-max` | `vo2max` | mL/kg/min |
| **Daily Steps** | `steps` | `steps` | Total count |

## 📋 Prerequisites

1. **Python 3.10+**
2. **Intervals.icu API Key**: Obtained from [Intervals.icu Settings](https://intervals.icu/settings).
3. **Google Cloud OAuth Credentials**: A `credentials.json` file for your Google Cloud Project with the Google Health API enabled.

---

## 🚀 Quick Setup Guide

### 1. Environment & Dependencies

Create a virtual environment and install dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Configure Credentials & Environment

Create a `.env` file in the project root:

```env
INTERVALS_API_KEY="your_intervals_api_key_here"
```

Ensure your Google OAuth `credentials.json` file is placed in the project root directory.

### 3. One-Time Google OAuth Authorization

Run the setup helper script to authorize access to your Google Health data:

```bash
.venv/bin/python auth_setup.py
```

1. Click the link generated by the script to open the Google login page.
2. Grant read permissions for your activity, health metrics, and sleep data.
3. After approving, Google will redirect your browser to a URL starting with `https://www.google.com/?code=...`.
4. Copy the full redirected URL from your browser address bar and paste it into the script prompt.

This creates `token.json` with a long-lived **refresh token**. Token renewal happens automatically in the background—you do **not** need to repeat this step.

---

## 🔄 Running the Sync Script

By default, the script syncs **past finalized days** (yesterday and the day before) to guarantee 100% complete step counts, sleep totals, and resting metrics:

```bash
.venv/bin/python fitbit_intervals_sync.py --days 2
```

- `--days N`: Specifies how many finalized days to sync (default: 2).
- `--include-today`: Optional flag if you want to push partial intraday metrics for today.

## 🖥️ Server Deployment Options

### Option A: Systemd Service & Timer (Recommended for Production)

Systemd is the most robust way to run scheduled scripts on Ubuntu/Linux because it provides automatic retries on network failures and clean logging in `journalctl`.

1. Create a service file `/etc/systemd/system/fitbit-sync.service`:

```ini
[Unit]
Description=Fitbit to Intervals.icu Health Data Sync
After=network-online.target

[Service]
Type=oneshot
User=giacomo
WorkingDirectory=/home/giacomo/fitbit-intervals-sync
ExecStart=/home/giacomo/fitbit-intervals-sync/.venv/bin/python fitbit_intervals_sync.py --days 2
Restart=on-failure
RestartSec=30s
```

2. Create a timer file `/etc/systemd/system/fitbit-sync.timer`:

```ini
[Unit]
Description=Run Fitbit Sync twice daily

[Timer]
OnCalendar=*-*-* 07:00,19:00
Persistent=true

[Install]
WantedBy=timers.target
```

3. Enable and start the timer:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now fitbit-sync.timer
```

---

### Option B: Crontab (Lightweight Alternative)

Crontab is simple and works natively on all Linux distributions.

```bash
crontab -e
```

Add a line to run the sync twice daily (e.g., 7:00 AM and 7:00 PM):

```cron
0 7,19 * * * cd /home/giacomo/fitbit-intervals-sync && .venv/bin/python fitbit_intervals_sync.py --days 2 >> /var/log/fitbit_intervals_sync.log 2>&1
```
